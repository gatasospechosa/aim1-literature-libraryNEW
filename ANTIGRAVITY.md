# Antigravity handoff

Open this project as a workspace in Google Antigravity IDE or Antigravity 2.0.

Suggested agent task:

> You are refining a personal interactive vision board called Dreamboard. Preserve the existing quiet editorial scrapbook aesthetic and local-first privacy. First inspect the code and run the app. Verify all existing behavior in the browser: creating/editing/deleting pins, photo upload and compression, drag movement, keyboard movement, category filters, search, export/import, mobile layout and persistence. Fix any issues you find without removing working features. Then improve polish only where it makes the board feel more tactile, personal and elegant; avoid generic SaaS-dashboard styling. Keep the project dependency-free and directly deployable to Vercel as a static site; do not introduce a build step unless it clearly improves the product. Do not add remote services unless explicitly requested.

If cross-device sync is wanted later, create a separate plan before coding. It should include authentication, a small database for dream metadata, and private object storage for images.
